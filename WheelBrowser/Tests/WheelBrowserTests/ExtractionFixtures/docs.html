Reader Mode API Guide

The reader mode API exposes one shared extraction service that can operate on either a live web view or a raw HTML document.

Usage

Use the web view entry point when a page depends on client-side rendering, authenticated state, or runtime DOM mutations that are not present in the original response body.

Use the HTML entry point when you already fetched a document and only need a normalized article model for indexing, summarization, or offline analysis.

Return Value

The extractor returns canonical title, cleaned article HTML, plain text content, optional byline and excerpt, and the source URL when one is known.

let extractor = ArticleExtractionService()
let article = try await extractor.extract(from: html, url: url, title: title)

Reader mode uses the cleaned article HTML for rendering, while semantic indexing and agent reading use the normalized plain text content.
